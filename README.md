# Gabi Spoleto Couto

I build focused tools for engineering workflows, maritime intelligence and CAD automation.
This profile is a short index of selected public work; the full portfolio is at
[gabriel-spoleto-couto-portfolio.gabichuuuuu.workers.dev](https://gabriel-spoleto-couto-portfolio.gabichuuuuu.workers.dev/).

## Selected work

- [solid_edge_mcp](https://github.com/gabichuuuuu/solid_edge_mcp) — local MCP server to model, assemble and draft in Solid Edge from Claude Code, Codex and other MCP clients (alpha, unofficial).
- [Nautic Analytics](https://github.com/gabichuuuuu/nautic-analytics-showcase) — preliminary mooring and buoy-system analysis (work in progress).
- [EU Maritime & Port Opportunity Monitor](https://github.com/gabichuuuuu/eu-maritime-port-opportunity-monitor-showcase) — procurement intelligence for ports and coastal infrastructure, available as an [Apify Actor](https://apify.com/gabichuuuuu/eu-maritime-port-opportunity-monitor).
- [SE_HardwareInserter](https://github.com/gabichuuuuu/SE_HardwareInserter) — Solid Edge add-in that inserts fasteners and anchors into assemblies.
- [SE_CadLinter](https://github.com/gabichuuuuu/SE_CadLinter) — configurable quality checks for Solid Edge documents.

## Working principles

I care about explicit assumptions, traceable results and useful validation.
The common thread is making specialist work easier to review, repeat and trust.
