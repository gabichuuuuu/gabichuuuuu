# Gabi Spoleto Couto

I build focused tools for engineering workflows, maritime intelligence and CAD automation.
This profile is a short index of selected public work.

- [EU Maritime & Port Opportunity Monitor](https://github.com/gabichuuuuu/eu-maritime-port-opportunity-monitor-showcase) — procurement intelligence for ports and coastal infrastructure.
- [agent-context](https://github.com/gabichuuuuu/agent-context) — portable rules and working memory for coding agents on Windows.
- [HardwareInserter](https://github.com/gabichuuuuu/HardwareInserter) — automated hardware insertion for Solid Edge assemblies.
- [CadLinter](https://github.com/gabichuuuuu/CadLinter) — configurable quality checks for Solid Edge documents.

## Working principles

I care about explicit assumptions, traceable results and useful validation.
The common thread is making specialist work easier to review, repeat and trust.
